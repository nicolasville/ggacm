# Utiliser un thème adapté à l'analyse de correspondance multiple

Cette fonction permet de générer un thème de graphique adapté aux ACM et
aux publications : Fond blanc, police Times New Roman, légende en bas du
graphique et transforme les axes en flèches.

## Usage

``` r
theme_acm(...)
```

## Arguments

- ...:

  Si vous voulez customiser le thème plus en profondeur, il est possible
  de rajouter des éléments qui seront passé à
  [`ggplot2::theme()`](https://ggplot2.tidyverse.org/reference/theme.html)

## Value

Un thème ggplot
