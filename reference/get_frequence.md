# Obtenir la fréquence des modalités

Obtenir la fréquence des modalités

## Usage

``` r
get_frequence(data_acm)
```

## Arguments

- data_acm:

  le data.frame à qui a été donné à manger à Factominer

## Value

un tableau qui renvoie pour chaque modalité le nombre d'individu
concerné (n) ainsi que leur pourcentage
